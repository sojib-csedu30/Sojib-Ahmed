Data Update Instruction

How to update AdmissionBD data.

01

Update admission data

Open script.js and edit the subjectData array. Replace demo rows with verified official subject allocation data, then commit changes to GitHub. GitHub Pages will update automatically.

02

Update exam countdown

Edit the examData array in script.js. Replace demo dates when official circulars are published.

03

Update university images

Edit the image URL in the universityData array. Use official university websites, Wikimedia Commons, or reusable public sources.

Professional Disclaimer

Unofficial prediction tool.

This is an unofficial prediction tool based on previous year available data. It is not an official guarantee. Final subject allocation depends on official authority, seat availability, migration, quota, admission rules, and yearly competition.

Merit positions are not directly comparable across different admission systems. For best accuracy, select the correct exam system.

Quota rules vary by university and subject. This is only an approximate adjustment.
